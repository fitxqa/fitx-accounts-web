# FitX Accounts — web version

Open: https://fitxqa.github.io/fitx-accounts-web/

Same accounts as the FitX Accounts Android app. Sign in with your FitX Accounts email and password.
Data is stored in Firebase and protected by sign-in and security rules; this repo only holds the app code.

Built from the private fitx-accounts repo (app/src/main/assets/www).
